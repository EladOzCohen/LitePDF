# LitePDF

קורא PDF קל ומהיר — פתקים בעברית (RTL מלא), מרקר, חתימה והדפסה. / A light PDF reader with RTL notes, highlighting, signing and printing.

## הפעלה
**גרסת exe:** `dist\LitePDF\LitePDF.exe` (אפשר להעתיק את כל התיקייה `dist\LitePDF` לכל מקום, ולהצמיד את ה-exe לשורת המשימות). בנייה מחדש: `tools\build_exe.ps1`.

או: לחיצה כפולה על `LitePDF.lnk` (אפשר להעתיק לשולחן העבודה או להצמיד לשורת המשימות).
פתיחת קובץ ישירות: גררו PDF לחלון, או `pythonw LitePDF.pyw קובץ.pdf`.

## מה אפשר לעשות
| פעולה | איך |
|---|---|
| פתק (Sticky note) | כפתור **פתק** ← לחיצה על הדף ← כתיבה. עברית/אנגלית, כל פסקה בכיוון שלה |
| מרקר | כפתור **מרקר** וגרירה על הטקסט (החץ לידו = צבעים). גרירה על אזור בלי טקסט = מלבן. קליק על סימון = הוספת הערה/מחיקה |
| קו תחתי / קו חוצה | כמו מרקר |
| חתימה | **חתימה ▸ חתימה חדשה** (ציור או הקלדה בפונט כתב-יד). נשמרת לספרייה. קליק = הנחה, אחר כך גרירה/שינוי גודל מהפינות |
| טקסט על הדף | כפתור **טקסט** (למילוי טפסים). ב-▾: V, X, תאריך של היום, גודל וצבע. לחיצה כפולה לעריכה |
| הדפסה | Ctrl+P — דיאלוג הדפסה רגיל (טווח עמודים, עותקים, מדפסת) |
| חיפוש | Ctrl+F |
| ביטול / מחיקה | Ctrl+Z / Delete |
| חלונית צד | F4 — עמודים, תוכן עניינים, רשימת כל ההערות |

קיצורים: V בחירה · H מרקר · N פתק · T טקסט · S חתימה · Ctrl+S שמירה · Ctrl+Shift+S שמירה בשם · Ctrl+גלגלת זום.

הכול נשמר **בתוך קובץ ה-PDF** כהערות סטנדרטיות. בשמירה ראשונה נשאל אם לדרוס את המקור או לשמור עותק.
